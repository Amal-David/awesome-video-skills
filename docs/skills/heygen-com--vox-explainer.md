## Before use

- The default is a 60–90 second collage idiom inspired by Vox, not Vox affiliation or automatic preservation of an existing brand style.
- Bundled seam scripts start a local browser/server; source retrieval and optional speech services have separate network, credential and cost requirements.
- Numeric motion and event-density checks are design heuristics; they do not establish factual accuracy, audio intelligibility or audience performance.
- A new narration recording requires new timing. Inspect the pinned script dependencies before installation.
- Static source inspection only; dependencies, rendering, listening and paid endpoints were not executed.

Read the whole upstream skill directory and its dependencies. Audit instructions/scripts and licensing before installation. The pinned link is evidence, not an instruction to execute it automatically.
